# 11. Последовательный (телеграфный) канал

> **Источники главы**
> * **[РСП § 10]** «Обмен по последовательному каналу» (с. 50–53) — нормативное описание
>   драйвера и всех пяти команд. Единственный полный источник.
> * **[РСП § 4.1.5]** — разряды 04, 05, 07 регистра 177716.
> * **[З]** «Системные регистры» — назначение разрядов, необходимость перемычек;
>   «Операторы прерывания» — перечень EMT 40…50.
> * **[МПСС]** (вторичный) — «последовательный программируемый интерфейс выполнен
>   программно», диапазон скоростей.

## 11.1. Общая характеристика

Последовательный интерфейс БК **выполнен программно**: аппаратного УАПП в машине нет,
драйвер сам формирует и декодирует биты, работая разрядами системного регистра 177716.

| Параметр | Значение |
| --- | --- |
| Линия | **четырёхпроводная**: 2 провода приём/передача информации, 2 — приём/передача сигналов готовности |
| Протокол | ИРПС [РСП] / R-232 [МПСС] — см. ⚠ ниже |
| Скорости | 50…9600 бод (9 фиксированных значений) |
| По включению питания | 9600 бод |
| Единица обмена | байт |
| Формат посылки | стартовый бит, 8 бит данных начиная с младшего, стоповый бит |

**Для реализации обмена требуется доработка микро-ЭВМ** — установка перемычек на плате
(перемычки 52 и 53 на принципиальной схеме), соединяющих вход и выход ТЛГ с контактами
разъёма УВВ (контакты В2 — приём, В3 — передача).

**Одновременный обмен с магнитофоном и по линии недопустим**: разряд 05 регистра 177716
используется и для передачи на магнитофон, и для сигнала готовности на линию.

> ⚠ **Расхождение по протоколу.** «Руководство системного программиста» называет протокол
> **ИРПС** (токовая петля 20 мА). Статья разработчиков (МПСС № 1, 1985) называет его
> **R-232** (RS-232, уровни напряжения). Диапазон скоростей в обоих источниках совпадает.
> Практически на БК применялись оба варианта — с внешним преобразователем уровней.
> Материалы по схемам ИРПС и переходникам ИРПС↔RS-232/USB — в каталоге `ИРПС/` архива.

### Разряды регистра 177716

| Направление | Разряд | Назначение | Исходное состояние |
| --- | --- | --- | --- |
| Запись | 04 | Данные на линию | «лог. 1» |
| Запись | 05 | Сигнал готовности на линию (либо данные на магнитофон) | «лог. 0» |
| Чтение | 04 | Данные с линии | — |
| Чтение | 07 | Сигнал готовности с линии | — |

Служебные ячейки системной области: `254` (`DLBIT`) — длина бита в условных единицах,
`256` (`KPORT`) — копия порта.

## 11.2. Прерывание обмена

Обмен по линии можно прервать клавишей **«СТОП»** — она вызывает немаскируемое прерывание
по вектору 4. Если рабочая программа это прерывание не обрабатывает, управление получит
пусковой монитор, который **выставит линию в исходное состояние** и перейдёт в диалоговый
режим.

## 11.3. Команды драйвера

### `EMT 40` — инициализация драйвера, установка скорости

**Вход:** `R0` — **номер** скорости (не сама скорость).

| Номер | Бод | | Номер | Бод |
| --- | --- | --- | --- | --- |
| 0 | 9600 | | 4 | 600 |
| 1 | 4800 | | 5 | 300 |
| 2 | 2400 | | 6 | 150 |
| 3 | 1200 | | 7 | 75 |
| | | | 10 | 50 |

Вызывается также из `EMT 14` при общей инициализации драйверов — с установкой 9600 бод.

### `EMT 42` — передача байта на линию

**Вход:** `R0` — младший байт на передачу.

Передача начинается с младшего бита, которому предшествует стартовый бит.

Перед передачей проверяется готовность приёмной стороны. **Если сигнала готовности нет,
драйвер уходит в цикл опроса**, из которого выходит только по появлению готовности либо
по прерыванию от клавиши «СТОП».

**На время передачи байта прерывания от внешних устройств маскируются.**

### `EMT 44` — приём байта с линии

**Выход:** `R0` — младший байт с линии.

Скорость передачи на линии должна совпадать с установленной в драйвере.

Драйвер выдаёт на линию сигнал готовности к приёму и переходит в режим ожидания стартового
бита; после приёма байта сигнал готовности сбрасывается. При поступлении стартового
сигнала прерывания от внешних устройств маскируются.

#### Прерываемое ожидание — важный приём

**На время ожидания байта драйвер разрешает прерывания от внешних устройств.** Это
позволяет, например, прервать ожидание с клавиатуры, получить новый символ, передать его
на линию и вернуться в драйвер — то есть реализовать полнодуплексный терминал.

Чтобы организовать такой алгоритм, рабочая программа должна:

1. установить режим работы с клавиатурой по прерыванию, поместив в ячейку **260** адрес
   своей программы обработки прерывания от клавиатуры;
2. в этой программе — **выставить линию в исходное состояние, записав константу `220`
   в регистр системного порта `@#177716`**, выполнить нужные действия и выйти командой
   `RTS PC`.

В процессе дальнейшего ожидания байта сигнал готовности на линии будет восстановлен.

```asm
        MOV     #KBINT,@#260    ; свой обработчик нажатия клавиши
        ...
        EMT     44              ; ждать байт с линии (прерываемо)
        ...
KBINT:  MOV     #220,@#177716   ; линия — в исходное состояние
        MOVB    @#104,R0        ; код нажатой клавиши
        EMT     42              ; передать его на линию
        RTS     PC              ; вернуться в драйвер приёма
```

### `EMT 46` — передача массива по линии

**Вход:** `R1` — адрес массива, `R2` — длина в байтах.
**Выход:** `R1` — адрес следующего за последним переданным байта, `R2` = 0.

### `EMT 50` — приём массива с линии

**Вход:** `R1` — адрес ОЗУ для массива, `R2` — длина в байтах.
**Выход:** `R1` — адрес следующего за последним принятым байта.

При отсутствии информации на линии работу драйвера можно прервать так же, как при `EMT 44`.

## 11.4. Загрузка программ по линии

Пусковой монитор умеет грузить файлы с линии командой **`ЛИНИЯ [адрес]`** (сокращённо `Л`)
на скорости **9600 бод**. Оглавление файла на линии — 4 байта:

```
слово 1 — адрес загрузки
слово 2 — длина массива
```

Если адрес в команде не задан, файл грузится по адресу из оглавления.
При ошибке чтения выдаётся сообщение `ОШИБКА`.

См. [08-монитор.md](08-монитор.md), §8.3.

## 11.5. Аппаратный блок ИРПС (БК-0010Ш)

Всё вышеописанное относится к **программному** каналу БК-0010 и БК-0010-01, где обмен
ведётся разрядами регистра 177716 и требует доработки платы.

В школьном варианте **«Электроника БК-0010Ш»** установлен **аппаратный блок ИРПС**:

| Адрес | Регистр |
| --- | --- |
| 176560 | Регистр состояния приёмника |
| 176562 | Буферный регистр приёмника |
| 176564 | Регистр состояния передатчика |
| 176566 | Буферный регистр передатчика |

| Вектор | Источник |
| --- | --- |
| 360 | Приёмник ИРПС |
| 364 | Передатчик ИРПС |

БК-Ш работает по протоколу ИРПС на фиксированной скорости **9600 бод**.
Побитовое описание регистров — в
[05-системные-регистры.md](05-системные-регистры.md), §5.5а.
