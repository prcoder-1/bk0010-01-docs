# 14.3. Игровые манипуляторы (джойстики)

> Документ каталога периферии — [../14-периферия.md](../14-периферия.md).
>
> **Источники раздела**
> * **[ПГС]** — паспорт **«Манипулятор игровой Электроника» ПГС2.082.000 ПС** (1991 г.),
>   фотокопия в `docs/joystick/photo_2025-01-18_14-58-55…58.jpg` и
>   `photo_2024-11-27_14-33-56/41/45.jpg`. Заводской документ: техданные, устройство,
>   таблица замыканий, принципиальная схема (рис. 5.2). Два разных экземпляра
>   (ОТК 107, вып. 10-91 и ОТК 134, вып. 03-92).
> * `docs/joystick/joystick.txt` — соответствие «контакт ↔ бит порта ↔ функция ↔ цвет провода».
> * `docs/joystick/БК_распайка_джойстика.png` — распайка «Джойвокс (Manwe)» на два
>   джойстика и реализация в эмуляторах.
> * **[Ус]** — Д. Ю. Усенков, «О некоторых периферийных устройствах для БК-0010»
>   (`docs/joystick/…html`, начало 1990-х) — альтернативная распайка, историческая справка.
> * **[ЭМ]** `bkemu-QT/devemu/Config.cpp`, массив `m_arJoystick_std`.

Джойстик подключается к **разъёму порта УВВ** и читается из **входного регистра `177714`**.
Никакой отдельной аппаратуры не требуется: манипулятор — это просто набор контактов,
замыкающих линии порта на общий провод.

## 14.3.1. Заводской манипулятор ПГС2.082.000 [ПГС]

| Параметр | Значение |
| --- | --- |
| Назначение | Ввод оперативной информации при работе игровых и обучающих программ |
| Принцип действия | Управление **герконами** с помощью постоянного магнита |
| Органы управления | Ручка управления с **восемью рабочими положениями** + две функциональные клавиши КЛ1 и КЛ2 |
| Габариты | 158 × 82 × 57 мм |
| Длина кабеля | не менее 700 мм |
| Масса | не более 0,25 кг |
| Коммутируемое напряжение | 1…10 В |
| Коммутируемый ток | 1…10 мА |
| Рабочая температура | 5…40 °C |

Выпускался в **трёх вариантах исполнения**, различающихся только соединителем на кабеле:

| Вариант | Соединитель | Назначение |
| --- | --- | --- |
| 1 | розетка **СНО63-64/95×9Р-24-2** | Для ПЭВМ типа **БК0010, БК0011** — подключается напрямую |
| 2 | вилка **ОНЦ-ВГ-11-7/16-В** | Подключается через розетку ОНЦ-ВГ-11-7/16-Р, входящую в комплект |
| 3 | без соединителя | Пользователь распаивает сам |

Сигналы выдаются **замыканием электрических цепей на общий провод**.

## 14.3.2. Таблица замыканий [ПГС]

Знаком `+` обозначены замкнутые цепи. Номера положений ручки — по рис. 5.1 паспорта.

| Контакт СНО63 | Контакт ОНЦ-ВГ | № бирки провода | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | КЛ1 | КЛ2 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| **В24** | 1 | 5 | + | + | | | | | + | | | |
| **А24** | 3 | 2 | | + | + | + | | | | | | |
| **В23** | 4 | 3 | | | | + | + | + | | | | |
| **В17** | 6 | 4 | | | | | | + | + | + | | |
| **В20** | 7 | 6 | | | | | | | | | + | |
| **А20** | 5 | 7 | | | | | | | | | | + |
| **В18, В19** (общий) | 2 | 1 | + | + | + | + | + | + | + | + | + | + |

> ⚠ **Опечатка в самом паспорте.** По рис. 5.1 положения ручки пронумерованы по кругу
> по часовой стрелке начиная с левого (⑨ часов): ① — 9 ч, ② — 10:30, ③ — 12 ч, ④ — 1:30,
> ⑤ — 3 ч, ⑥ — 4:30, ⑦ — 6 ч, ⑧ — 7:30. Значит **основные** (одноконтактные) положения —
> 1, 3, 5, 7, а диагональные (двухконтактные) — 2, 4, 6, 8. Каждый контакт направления
> должен замыкаться в трёх подряд идущих положениях: В24 = {8, 1, 2}, А24 = {2, 3, 4},
> В23 = {4, 5, 6}, В17 = {6, 7, 8}.
>
> В напечатанной таблице третий знак в строке **В24 стоит под 7, а не под 8** — тогда
> одноконтактными оказываются положения 1, 3, 5, **8**, что противоречит геометрии рис. 5.1.
> Проверено по **двум разным экземплярам** паспорта (выпуска 10-91 и 03-92) — знак стоит
> одинаково, то есть это ошибка набора, воспроизведённая всем тиражом.
> **Правильно: В24 = {8, 1, 2}.**

## 14.3.3. Распайка на порт БК

Основная (заводская) распайка. Сверена с таблицей разрядов порта
([разъёмы.md](разъёмы.md), §14.1.2) —
контакты совпадают полностью:

| Бит порта | Маска | Контакт УП | Функция | Цвет провода |
| --- | --- | --- | --- | --- |
| 0 | `000001` | **В24** | Вверх | жёлтый |
| 1 | `000002` | **А24** | Вправо | синий |
| 2 | `000004` | **В23** | Вниз | красный |
| 3 | `000010` | **В17** | Влево | зелёный |
| 4 | `000020` | **В20** | Кнопка A (КЛ1) | |
| 5 | `000040` | **А20** | Левая кнопка (КЛ2) | коричневый |
| 6 | `000100` | **В22** | Правая кнопка | серый |
| 7 | `000200` | **А23** | Кнопка B | |
| — | | **В18**, **В19** | Общий (GND) | |

Заводской манипулятор задействует только биты 0…5 (четыре направления и две клавиши);
биты 6 и 7 используются джойстиками сторонних изготовителей.

> Контакт для бита 7 в `joystick.txt` не указан; **А23** получен из таблицы разрядов
> порта ([разъёмы.md](разъёмы.md), §14.1.2) и подтверждён распайкой «Джойвокс».

## 14.3.4. Второй джойстик — старший байт порта

Порт УВВ 16-разрядный, поэтому к нему подключаются **два джойстика одновременно**:
второй занимает биты 8…15. Распайка «Джойвокс (Manwe)», сверена с
[разъёмы.md](разъёмы.md), §14.1.2:

| Бит порта | Маска | Контакт УП | Функция |
| --- | --- | --- | --- |
| 8 | `000400` | В31 | Вверх |
| 9 | `001000` | А31 | Вправо |
| 10 | `002000` | В32 | Вниз |
| 11 | `004000` | А32 | Влево |
| 12 | `010000` | В30 | Start |
| 13 | `020000` | А29 | A |
| 14 | `040000` | В29 | B |
| 15 | `100000` | А30 | Select |

В этой распайке кнопки первого джойстика названы иначе: бит 4 — Start, 5 — A, 6 — B,
7 — Select. Электрически это те же контакты В20, А20, В22, А23.

> В исходном файле `БК_распайка_джойстика.png` ряд разъёма обозначен буквой **Б**
> (Б31, Б32, Б30, Б29). Здесь приведено обозначение **В**, принятое в [разъёмы.md](разъёмы.md) и во всей
> остальной документации, — речь об одном и том же физическом ряде контактов.

## 14.3.5. Чтение джойстика из программы

Работа с портом **системным программным обеспечением не поддержана** (см.
[../06-системные-регистры.md](../06-системные-регистры.md), §6.5) — обращаться нужно
непосредственно по физическому адресу.

**Порт инвертирующий**: замыкание контакта на общий провод даёт низкий уровень,
который читается как **логическая 1**. То есть нажатому направлению или кнопке
соответствует **единичный бит**.

```asm
        MOV     @#177714,R0     ; прочитать состояние джойстика
        BIT     #1,R0           ; вверх?
        BNE     UP
        BIT     #2,R0           ; вправо?
        BNE     RIGHT
        BIT     #40,R0          ; основная кнопка?
        BNE     FIRE
```

Диагональ распознаётся по двум одновременно установленным битам направления —
это прямое следствие таблицы замыканий.

Реализация в эмуляторах (`bkemu-QT/devemu/Config.cpp`, `m_arJoystick_std`; то же
в эмуляторе gid) совпадает с приведёнными масками. В эмуляторе gid биты `000040`
и `000100` разделяются с левой и правой кнопками мыши, а направления — с её
перемещением.

## 14.3.6. ⚠ Альтернативная распайка [Ус]

В начале 1990-х в магазине «Электроника» появился джойстик другой конструкции —
меньше прежнего ПУ-1, с тремя распараллеленными кнопками, на **герконах**, с плоским
кабелем **без разъёма** (распайка возлагалась на пользователя), ценой 64 рубля.
К нему прилагалась таблица распайки, названная «стандартной»:

| Обозначение | Команда | Контакт порта | Бит | Функция по заводской распайке |
| --- | --- | --- | --- | --- |
| ↑ | вперёд | В23 | 2 | вниз |
| ← | влево | В24 | 0 | вверх |
| ↓ | назад | В17 | 3 | влево |
| → | вправо | А24 | 1 | вправо |
| •← | левая кнопка | В22 | 6 | правая кнопка |
| →• | правая кнопка | В20 | 4 | кнопка A |
| ↑ | верхняя кнопка | А20 | 5 | левая кнопка |
| \| | общий | А18, А19, В18 или В19 | — | общий |

**Совпадает только «вправо».** Остальные три направления назначены иначе.

Сам автор оговаривает: «пока не все игры соответствуют этому стандарту, поэтому для них,
возможно, потребуется изменение в программе игры».

**Вердикт: пользоваться заводской распайкой** (таблица выше). Её подтверждают паспорт
ПГС2.082.000, `joystick.txt`, распайка «Джойвокс» и все известные эмуляторы.

## 14.3.7. Третий вариант: герконовый джойстик [Схемы]

В коллекции схем на форуме MAXIOL приведена ещё одна распайка герконового
джойстика — она не совпадает ни с заводской, ни с [Ус]:

| Функция | Контакт | Что это по заводской распайке |
| --- | :-: | --- |
| Вверх | **В24** | вверх ✓ |
| Вниз | **В23** | вниз ✓ |
| Влево | **В17** | влево ✓ |
| Вправо | **А24** | вправо ✓ |
| Левая кнопка | **В22** | правая кнопка (разряд 6) |
| Правая кнопка | **А21** | в таблице разрядов порта (§14.1.2) **не задействован** |
| Общий | **В19** | общий ✓ |

**Все четыре направления и общий провод совпадают с заводскими.** Это важно
само по себе: получается независимое подтверждение заводского назначения
направлений — против [Ус], где они переставлены. Расходятся только кнопки:
левая посажена на В22 (по заводской таблице это правая), а правая — на **А21**,
контакт, который в [разъёмы.md](разъёмы.md) (§14.1.2, §14.1.5) значится
незадействованным ни на УП, ни на МПИ.

Вывод прежний: как норму принимаем заводскую распайку, а этот вариант полезно
знать тем, кому достался такой джойстик — переназначать придётся только кнопки.

Часть игр умела подстраиваться под произвольную распайку. Например, в игре **ZOOM**
(меню «Управление» → «нестандартный джойстик») на запросы вводится «Состояние порта
вывода» = 0, «Маска ввода» = `177700`, после чего покачиванием ручки и нажатием кнопок
машине указывают, какими действиями задаются команды из списка; в конце выбирается
«от джойстика» либо «параллельное» (джойстик и клавиатура). Аналогично устроен **XONIX**.

## 14.3.8. Историческая справка [Ус]

* **ПУ-1** — первый пульт управления (джойстик) для БК, описан в «Вычислительной технике»
  № 8 за 1990 г.; четыре кнопки, но **не распараллеленные**, обычные пластинчатые контакты.
* **УВК-1** — координатное устройство ввода («мышь») для БК, там же. Серийно
  выпускавшаяся версия — «Марсианка» (заводской индекс **УВК-01**), см. [мышь-УВК-01.md](мышь-УВК-01.md).
* Джойстик 1990 г. — три распараллеленные кнопки, герконы (существенно надёжнее
  пластинчатых контактов ПУ-1).
