# 14.9. Видеомонитор «Электроника 32ВТЦ-201» (МС6113)

> Документ каталога периферии — [../14-периферия.md](../14-периферия.md).
>
> **Источник** — **[Ус]**: Д. Ю. Усенков, «О некоторых периферийных устройствах для БК-0010»
> (начало 1990-х).

Переносной цветной монитор на базе телевизора «Юность», рассчитанный на подключение
БК и «Агата»; на задней стенке два отдельных разъёма.

| Параметр | Значение |
| --- | --- |
| Размер экрана | 154 ± 8 × 219 ± 10 мм |
| Разрешение | 256 × 256 точек либо 32 символа × 32 строки (у БК часть поля остаётся незаполненной) |
| Цветов | не менее 8 (для «Агата»); для БК-0010.01 — три, программно больше |
| Вход для БК | низкочастотный, **RGB по трём отдельным линиям** + «синхронизация» |
| Масса | около 13 кг |

Распиновка выхода «ЦТВ» БК, к которому подключается монитор, —
[разъёмы.md](разъёмы.md), §14.1.9.

Актуально потому, что в отечественных телевизорах видеовхода не было и подключение
БК обычно требовало вмешательства в схему телевизора.
