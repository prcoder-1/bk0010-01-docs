# 14.5. Звуковой сопроцессор AY-3-8910 и его расширения

> Документ каталога периферии — [../14-периферия.md](../14-периферия.md).
>
> **Источники**
> * **[КП]** — «Компьютерная ПРАВДА», выпуск `kpss14`: протокол обращения через `177714`.
> * **[ЭМ]** — `bkemu-QT/devemu/Board.cpp`, обработка адреса `177714`.
> * **[2AY]** — тема форума maxiol.com о подключении двух звуковых чипов AY/YM2149F.

Штатного звукогенератора в БК нет: звук выдаётся разрядом 06 регистра 177716
(см. [../06-системные-регистры.md](../06-системные-регистры.md), §6.6). Позднее к порту УВВ
стали подключать **музыкальный сопроцессор AY-3-8910** (он же AY-8910) — тот же чип,
что применялся в ZX Spectrum и в отечественных клонах.

Протокол обращения к нему через порт **177714** необычен и опирается на то, что порт
различает словную и байтовую запись:

| Операция | Действие |
| --- | --- |
| **Запись слова** — `MOV #КОД,@#177714` | **Выбор внутреннего регистра** сопроцессора |
| **Запись байта** — `MOVB #ЧИСЛО,@#177714` | **Запись данных** в выбранный регистр |

У сопроцессора 16 внутренних регистров (три канала тона, шум, огибающая, управление
смешиванием и два порта ввода-вывода — стандартный набор AY-3-8910).

Источник — **[КП]**, выпуск `kpss14`. **Подтверждено [ЭМ]**: в `bkemu-QT/devemu/Board.cpp`
(`case 0177714`) при байтовой операции вызывается `synth_write_data(LOBYTE(src))`,
при словной — `synth_write_address(src)`. То есть эмулятор реализует ровно тот протокол,
который описан в газете 1992 года.

> Через тот же адрес подключаются и другие звуковые расширения — **Covox**
> (простой ЦАП на резисторах, данные пишутся прямо в порт) и «Менестрель».
> В эмуляторе они обслуживаются параллельно с AY: `m_pCovox->SetData(src)`,
> `m_pMenestrel->SetData(src)`.

Поскольку AY, Covox и принтер пишут в один и тот же младший байт порта вывода,
одновременно на порту может работать только одно из этих устройств — сводка
занятых разрядов в [разъёмы.md](разъёмы.md), §14.1.3. Звуковой блок контроллера
AZБК обходит это ограничение собственными адресами (§14.5.1 ниже;
[../19-AZБК.md](../19-AZБК.md), §19.7).

## 14.5.1. Два чипа: TurboSound и «2AY» [2AY]

Более позднее самодельное расширение — плата с **двумя** звуковыми чипами
(AY-3-8910/8912 или **YM2149F**, программно совместимый аналог) вместо одного.
Известны два независимых протокола выбора активного чипа:

* **TurboSound** — общий для ретро-платформ стандарт (изначально придуман для
  ZX Spectrum). Номер активного чипа задаётся отдельной записью **слова** в
  177714: значение **255** выбирает AY№1, **254** — AY№2; последующие обращения
  «словом → выбор регистра / байтом → данные» адресуются уже выбранному чипу.
  После аппаратного сброса порт 177714 читается как «минус один» (все разряды
  единичные), поэтому по умолчанию активен AY№1.
* **«2AY»** (реализация, применённая в контроллере AZБК) — вместо переключения
  одного порта заводит для каждого чипа **отдельную пару адресов**, поэтому
  оба AY доступны одновременно, без переключения:

  | Адрес | Назначение |
  | --- | --- |
  | 177172 | Выбор внутреннего регистра **AY№1** (запись) |
  | 177173 | Данные **AY№1** (чтение/запись) |
  | 177174 | Выбор внутреннего регистра **AY№2** (запись) |
  | 177175 | Данные **AY№2** (чтение/запись) |

  Обращения к парам 177172/177173 и 177174/177175 не влияют друг на друга —
  оба чипа работают полностью независимо.

Отдельно от протокола обмена стоит вопрос тактовой частоты: помимо паспортной
для AY-3-8910 частоты **1,5 МГц**, на платах с YM2149F часто ставят
**1 789 772,75 Гц** — это ровно половина частоты цветовой поднесущей NTSC
(3 579 545,45 Гц), выбранная ради совместимости с частотами, уже привычными
по другим платформам с тем же чипом (в том числе с готовыми плеерами музыки).
