# 14.11. Контроллер локальной сети БК-0011 (КЛС)

> Документ каталога периферии — [../14-периферия.md](../14-периферия.md).
>
> **Источник** — **[РД-11]**: «Персональная ЭВМ Электроника МС 0513». Инструкция по
> ремонту 3.057.004 РД, 1988, разделы 9 и 10. Сведения о самой БИС 1801ВП1-065 —
> [../13-последовательный-канал.md](../13-последовательный-канал.md), §13.6 [k1801].

КЛС — блок для классов из нескольких БК-0011: машины учеников (варианты -01/-02)
и машина преподавателя (-03/-04, с КРМП) соединяются в **кольцо**
([../02-БК-0011.md](../02-БК-0011.md), §2.1а). [РСП-11] называет то же устройство
«КМК — контроллер моноканала».

## 14.11.1. Устройство

| Узел | Элементы | Назначение |
| --- | --- | --- |
| Генератор 4608 кГц | D11.1–D11.3 | Задаёт скорость обмена |
| **Приёмопередатчик** | **D1 — К1801ВП1-065** (SART) | Подключение к МПИ и преобразование байт ↔ последовательный код |
| Выбор устройства (ВУ) | D11.4–D11.6, D4.3 | Низкий уровень при адресе `160000`…`177776` |
| Режим работы | перемычки 31-32, 33-34 (адреса), 35-36, 37-38, 39-40 (формат), 41-42, 43-44, 45-46 (скорость) | Задают выводы ВП1-065 |
| **Сетевой адрес** 0…255 | переключатели SA1 (ВДМ1-8), резисторы E2.1, D2, D3.1, D3.2, D5.3 | Читается в разрядах 8–11, 13, 14 буферного регистра приёмника |
| **Электронный шунт** | D7.3, D7.4 | Замыкает выход приёмника на вход передатчика: станция ретранслирует кольцо, не участвуя в обмене |
| Входной узел приёмника | D7.1, D7.2, трансформатор TU1 | Импульсы тока в линии → логический сигнал; гальваническая развязка |
| Выходной узел передатчика | D9, D10, трансформатор TU2 | Логический сигнал → импульсы тока **650 ±20 нс**; гальваническая развязка |
| **Электромеханический шунт** | D5.4, D6, D3.3, D3.4, D4.2, UT1 | Замыкает кольцо при выключенной станции |
| Таймер | D8, D3.5, D4.1, D5.1, D5.2 | Если электронный шунт разомкнут, а к регистрам приёмника не обращались **более 2,5 с** (и нет сигнала «ОСТ»), включает электромеханический шунт |

Линия — **токовая петля 20 мА** с трансформаторной развязкой; инструкция называет
интерфейс «ИРПС» (радиальный последовательный). Скорость в БК-0011 — **57 600 бод**,
формат — старт, **8 бит**, бит чётности, стоп.

Таймер нужен, чтобы зависшая или выключенная машина не рвала кольцо: пока программа
опрашивает сеть, станция активна, а через 2,5 с молчания кольцо замыкается в обход неё.

## 14.11.2. Регистры [РД-11, табл. 31–32]

| Адрес | Регистр |
| --- | --- |
| `176560` | Состояние приёмника (РСПр) |
| `176562` | Буфер приёмника (БРПр) |
| `176564` | Состояние передатчика (РСПер) |
| `176566` | Буфер передатчика (БРПер) |

| Вектор | Источник |
| :-: | --- |
| `360` | Приёмник |
| `364` | Передатчик |

Это та же конфигурация ВП1-065 (`ACL1-0`, базовый адрес `176560`), что в блоке
ИРПС БК-0010Ш ([../13-последовательный-канал.md](../13-последовательный-канал.md),
§13.5–13.6). Векторы по [РСП-11] — другие: см. ниже.

### Состояние приёмника `176560`

| Разряд | Доступ | Назначение |
| :-: | --- | --- |
| 15 | чтение | Ошибка чётности в принятом слове; сбрасывается чтением БРПр и `INIT` |
| 12 | чтение | Переполнение: пришло второе слово, а первое не прочитано (в БРПр остаётся первое) |
| 07 | чтение | Флаг: слово принято; запрос прерывания, если установлен и разряд 06 |
| 06 | чтение/запись | Разрешение прерывания от приёмника |
| **02** | **запись** | **Электронный шунт:** «1» — ретрансляция принимаемых посылок, «0» — передача от своей машины. Читается как «0» |
| 0, 1, 3…5 | — | Не используются, читаются нулями |

Разряд 02 — дополнение КЛС к ВП1-065: по записи в `176560` схема управления
шунтом запоминает его значение.

### Состояние передатчика `176564`

| Разряд | Доступ | Назначение |
| :-: | --- | --- |
| 07 | чтение | Флаг: передатчик готов принять слово |
| 06 | чтение/запись | Разрешение прерывания от передатчика |
| 02 | чтение/запись | «Проверка»: передаваемое слово попадает в приёмник, приём с линии закрыт |
| 00 | чтение/запись | Разрыв линии: на выходе держится «старт» |

### Буферы

* **БРПр `176562`** (чтение): разряды 07…00 — принятый байт (в разряде 0 — первый
  бит посылки), разряды **8–11, 13, 14 — сетевой адрес станции** с переключателей
  SA1.
* **БРПер `176566`** (запись): разряды 07…00 — байт для передачи; посылка уходит
  в линию по окончании записи.

## 14.11.3. Режимы ВП1-065 [РД-11, табл. 33–37]

Инструкция приводит полную таблицу настроек микросхемы. Она совпадает
с [k1801] (§13.6) с двумя уточнениями:

* **формат слова** — по входам `NB0`, `NB1`: 5, 7 или 8 бит; [k1801] описывает только
  `NB0` (7/8 бит);
* при передаче формируются **два стоп-бита**.

| `ACLO`, `ACL1` | Базовый адрес | Векторы |
| :-: | --- | --- |
| 00 | `177560` | `060` / `064` |
| 10 | `176560` | `360` / `364` |
| 01 | `176570` | `370` / `374` |
| 11 | по `BS` | `xx0` / `xx4` |

Порядок разрядов в обозначении здесь обратный тому, что принят в §13.6
(`ACL1-0`), конфигурация та же.

Состояние линии определяется входами `DCLO`, `BSYD` и разрядом 00 РСПер
[табл. 34]: при `DCLO` = 1, `BSYD` = 0, разряд 00 = 0 линия свободна и слово
выдаётся; при разряде 00 = 1 — «разрыв» (высокий уровень, «старт»); при
`BSYD` = 1 линия занята («стоп»); при `DCLO` = 0 — занята из-за аварии питания.

## 14.11.4. Разъёмы [РД-11, табл. 38–41]

**МПИ (XT1)** — стандартный набор: AD00…AD15, СИА, СИП, ППР2 (`IAKO`),
ТПР (`VIRQ`), ПРТ, СБРОС, ВЫВОД, ВВОД, ОСТ, Е, +5 В, общий.

**«ЛС» — к сети (XT2)**, 10 контактов:

| Контакт | Сигнал |
| :-: | --- |
| 1, 2 | Вход 1, Вход 2 |
| 5 | Управление |
| 7 | Технологический |
| 9, 10 | Выход 1, Выход 2 |
| 3, 4, 6, 8 | Общий |

## 14.11.5. КРМП — КЛС и КНГМД в одном корпусе [РД-11 § 10]

Блок КРМП («контроллер рабочего места пользователя», в другом месте инструкции —
«преподавателя») объединяет платы КЛС и КНГМД, соединённые гибкими проводниками
(3.059.002 СБ). Платы работают независимо. Разъёмы: «ЛС» (как выше) и «НГМД»
(34 контакта, как в [НГМД.md](НГМД.md), §14.2.6).

## 14.11.6. Чего нет и что не сходится

* **Вектор.** [РСП-11] относит к «блоку КМК» вектор **`300`**, [РД-11] — векторы
  **`360`/`364`**. Перемычки 31-32/33-34 меняют конфигурацию ВП1-065, так что верны
  могут быть оба числа для разных комплектаций. Драйвер сети (прошивка **254**,
  «Локальная сеть БК-0011Ш», [../15-схемотехника-и-доработки.md](../15-схемотехника-и-доработки.md),
  §15.1б) в архиве отсутствует, и проверить нечем. В реестре — И15.
* **Протокол сети** (формат кадра, адресация, роль преподавателя) в [РД-11]
  не описан — только аппаратура.
* Начальный пуск ДМС ищет КЛС и при наличии запускает **загрузчик по сети**
  ([../02-БК-0011.md](../02-БК-0011.md), §2.7а); монитор умеет загружать файлы
  «из линии» (команда `L`).
