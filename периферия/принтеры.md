# 13.7. Принтеры

> Документ каталога периферии — [../13-периферия.md](../13-периферия.md).
>
> **Источники** — **[Ус]**: Д. Ю. Усенков, «О некоторых периферийных устройствах для БК-0010»
> (начало 1990-х); **[РД-11]**: инструкция по ремонту БК-0011 3.057.004 РД, раздел 8 ([§13.7.3](#s13.7.3)).

Принтер подключается к порту УВВ по протоколу «строб + готовность»: разряды 00–07
порта вывода — код символа, разряд 08 порта вывода — строб, разряд 08 порта ввода —
готовность (контакты — [разъёмы.md](разъёмы.md), [§13.1.2](разъёмы.md#s13.1.2); конфликт разряда 08 со
вторым джойстиком — [§13.1.3](разъёмы.md#s13.1.3)). Подробности протокола и пример драйвера см. в
[../07-монитор.md](../07-монитор.md), [§7.11](../07-монитор.md#s7.11) и [§7.12](../07-монитор.md#s7.12).

Типовые принтеры эпохи — **МС-6312**, **МС-6313**, «Роботрон».

<a id="s13.7.1"></a>

## 13.7.1. МС-6312 [Ус]

Термоструйный: точка печатается «выстреливанием» разогретого состава.

| Параметр | Значение |
| --- | --- |
| Габариты, масса | 53,5 × 170 × 277 мм, не более 3 кг |
| Символов в строке | 80 |
| Скорость печати | 150 знаков/с (шрифт ELITE) |
| Набор знаков | не менее 162 |
| Шаг печати / шаг строк | 2,12 мм / 4,23 мм |
| Матрица символа | 16 × 12 точек |
| Минимальная толщина линии | 0,4 мм |
| Бумага | обычная, формат А4 или рулон той же ширины |

Варианты шрифта: уплотнённый (обычный), расширенный, подчёркнутый, «жирный»
(двойное пропечатывание), линия подчёркивания, верхние индексы, субскрипты.

Управление — **ESCAPE-последовательности**; система команд близка к EPSON-стандарту
(коды инициализации и графического режима — см. пример графического копирования экрана
в [../07-монитор.md](../07-монитор.md), [§7.12](../07-монитор.md#s7.12)). Существенный недостаток: пишущий узел
одноразовый и требует замены по мере израсходования.

<a id="s13.7.2"></a>

## 13.7.2. МС-6313 [Ус]

Матричный, девять игл, красящая лента. Габариты 400 × 460 × 100 мм, масса около 8 кг.
Тип шрифта переключается **вручную** движками под крышкой. Канал передачи — **ИРПС-М**
(как в КУВТ-86 для связи с ДВК) либо стык С2; кабели с разъёмами прилагаются.

Твёрдая копия экрана печатается передачей вместо кода символа числа, кодирующего
участок изображения под гребёнкой игл: иглы, соответствующие единичным битам, печатают
точки, нулевым — нет.

<a id="s13.7.3"></a>

## 13.7.3. КПУ БК-0011: интерфейс ИРПР [РД-11]

Для БК-0011 принтер подключался через заводской **КПУ** — контроллер печатающего
устройства (3.059.003 Э3), стоящий между разъёмом «УП» и кабелем принтера.
Программно это тот же порт `177714`: байт — в разряды 07…00, строб и готовность —
разряд 14 ([../19-БК-0011.md](../19-БК-0011.md), [§19.10](../19-БК-0011.md#s19.10)). Инструкция по ремонту
3.057.004 РД (раздел 8) описывает его электрически.

* Интерфейс — **ИРПР по ОСТ 25778-82** (байтовый параллельный, тот же класс, что
  Centronics). Мозаичное печатающее устройство подключается к ППИ машины.
* D1, D2 — усилители выходов порта, выходной ток лог. 0 — до 40 мА.
* R1, R2 — согласование с волновым сопротивлением ленточного кабеля **110 ±20 Ом**.
* Регистр данных — порт ППИ на К555ИР23 (D15, D16) в самой машине.

| Сигнал ИРПР | Назначение |
| --- | --- |
| Д-И (D0…D7) | Данные от источника информации |
| СТР-ИН | Строб источника: данные выставлены |
| ГИ-ИН | Готовность источника к выдаче данных |
| ГП-ПН | Готовность приёмника (низкий уровень) |

**Протокол (рис. 50).** Машина может выдать байт, когда ГП — низкий. Она выставляет
D0…D7 и не раньше чем через **150 нс** опускает СТР. Приняв байт, принтер снимает
ГП (высокий уровень); после этого машина снимает СТР и готовит следующий байт.

> **[✓ ПЗУ]** Именно так печатает тест МСТД БК-0011 (прошивка 203): ждёт «1»
> в разряде 14 порта `177714` по чтению, записывает код в младший байт, ставит
> строб записью разряда 14, ждёт, пока готовность пропадёт, затем снимает строб
> и обнуляет порт. Сигналы проходят через инвертирующие усилители, поэтому
> «низкий ГП» на кабеле программа видит как «1».
