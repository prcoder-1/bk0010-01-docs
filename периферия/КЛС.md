# 13.11. Контроллер локальной сети БК-0011 (КЛС)

> Документ каталога периферии — [../13-периферия.md](../13-периферия.md).
>
> **Источник** — **[РД-11]**: «Персональная ЭВМ Электроника МС 0513». Инструкция по
> ремонту 3.057.004 РД, 1988, разделы 9 и 10. Сведения о самой БИС 1801ВП1-065 —
> [../12-последовательный-канал.md](../12-последовательный-канал.md), [§12.6](../12-последовательный-канал.md#s12.6) [k1801].

КЛС — блок для классов из нескольких БК-0011: машины учеников (варианты -01/-02)
и машина преподавателя (-03/-04, с КРМП) соединяются в **кольцо**
([../19-БК-0011.md](../19-БК-0011.md), [§19.1](../19-БК-0011.md#s19.1)). [РСП-11] называет то же устройство
«КМК — контроллер моноканала».

<a id="s13.11.1"></a>

## 13.11.1. Устройство

| Узел | Элементы | Назначение |
| --- | --- | --- |
| Генератор 4608 кГц | D11.1–D11.3 | Задаёт скорость обмена |
| **Приёмопередатчик** | **D1 — К1801ВП1-065** (SART) | Подключение к МПИ и преобразование байт ↔ последовательный код |
| Выбор устройства (ВУ) | D11.4–D11.6, D4.3 | Низкий уровень при адресе `160000`…`177776` |
| Режим работы | перемычки 31-32, 33-34 (адреса), 35-36, 37-38, 39-40 (формат), 41-42, 43-44, 45-46 (скорость) | Задают выводы ВП1-065 |
| **Сетевой адрес** 0…255 | переключатели SA1 (ВДМ1-8), резисторы E2.1, D2, D3.1, D3.2, D5.3 | Читается в разрядах 8–11, 13, 14 буферного регистра приёмника |
| **Электронный шунт** | D7.3, D7.4 | Замыкает выход приёмника на вход передатчика: станция ретранслирует кольцо, не участвуя в обмене |
| Входной узел приёмника | D7.1, D7.2, трансформатор TU1 | Импульсы тока в линии → логический сигнал; гальваническая развязка |
| Выходной узел передатчика | D9, D10, трансформатор TU2 | Логический сигнал → импульсы тока **650 ±20 нс**; гальваническая развязка |
| **Электромеханический шунт** | D5.4, D6, D3.3, D3.4, D4.2, UT1 | Замыкает кольцо при выключенной станции |
| Таймер | D8, D3.5, D4.1, D5.1, D5.2 | Если электронный шунт разомкнут, а к регистрам приёмника не обращались **более 2,5 с** (и нет сигнала «ОСТ»), включает электромеханический шунт |

Линия — **токовая петля 20 мА** с трансформаторной развязкой; инструкция называет
интерфейс «ИРПС» (радиальный последовательный). Скорость в БК-0011 — **57 600 бод**,
формат — старт, **8 бит**, бит чётности, стоп.

Таймер нужен, чтобы зависшая или выключенная машина не рвала кольцо: пока программа
опрашивает сеть, станция активна, а через 2,5 с молчания кольцо замыкается в обход неё.

<a id="s13.11.2"></a>

## 13.11.2. Регистры [РД-11, табл. 31–32]

| Адрес | Регистр | Вектор |
| --- | --- | :-: |
| `176560` | Состояние приёмника (РСПр) | `360` — приёмник |
| `176562` | Буфер приёмника (БРПр) | |
| `176564` | Состояние передатчика (РСПер) | `364` — передатчик |
| `176566` | Буфер передатчика (БРПер) | |

Это та же БИС и та же конфигурация (`ACL1-0` = 01), что в блоке ИРПС БК-0010Ш, поэтому
**разряды регистров — как в [../04-системные-регистры.md](../04-системные-регистры.md),
[§4.6](../04-системные-регистры.md#s4.6)**, а конфигурация микросхемы (формат, скорость, адреса по `ACL1-0`) — как в
[../12-последовательный-канал.md](../12-последовательный-канал.md), [§12.6](../12-последовательный-канал.md#s12.6). Векторы
по [РСП-11] — другие: см. [§13.11.5](#s13.11.5).

КЛС добавляет к регистрам микросхемы два своих поля:

| Где | Разряды | Назначение |
| --- | --- | --- |
| РСПр `176560`, **запись** | **02** | **Электронный шунт:** «1» — ретрансляция принимаемых посылок, «0» — передача от своей машины. Значение запоминает схема управления шунтом; при чтении разряд — «0» |
| БРПр `176562`, чтение | **8–11, 13, 14** | **Сетевой адрес станции** с переключателей SA1 |

> [РД-11, табл. 32] относит разряд 00 РСПр к неиспользуемым, тогда как по [k1801]
> это индикатор разрыва линии ([§21.5](../21-реестр-расхождений.md#s21.5), А8). Для КЛС разряд не важен: о разрыве
> кольца станция узнаёт по таймеру шунта.

## 13.11.3. Разъёмы [РД-11, табл. 38–41]

**МПИ (XT1)** — стандартный набор: AD00…AD15, СИА, СИП, ППР2 (`IAKO`),
ТПР (`VIRQ`), ПРТ, СБРОС, ВЫВОД, ВВОД, ОСТ, Е, +5 В, общий.

**«ЛС» — к сети (XT2)**, 10 контактов:

| Контакт | Сигнал |
| :-: | --- |
| 1, 2 | Вход 1, Вход 2 |
| 5 | Управление |
| 7 | Технологический |
| 9, 10 | Выход 1, Выход 2 |
| 3, 4, 6, 8 | Общий |

<a id="s13.11.4"></a>

## 13.11.4. КРМП — КЛС и КНГМД в одном корпусе [РД-11 § 10]

Блок КРМП («контроллер рабочего места пользователя», в другом месте инструкции —
«преподавателя») объединяет платы КЛС и КНГМД, соединённые гибкими проводниками
(3.059.002 СБ). Платы работают независимо. Разъёмы: «ЛС» (как выше) и «НГМД»
(34 контакта, как в [НГМД.md](НГМД.md), [§13.2.6](НГМД.md#s13.2.6)).

<a id="s13.11.5"></a>

## 13.11.5. Чего нет и что не сходится

* **Вектор.** [РСП-11] относит к «блоку КМК» вектор **`300`**, [РД-11] — векторы
  **`360`/`364`**. Перемычки 31-32/33-34 меняют конфигурацию ВП1-065, так что верны
  могут быть оба числа для разных комплектаций. Драйвер сети (прошивка **254**,
  «Локальная сеть БК-0011Ш», [../14-схемотехника-и-доработки.md](../14-схемотехника-и-доработки.md),
  [§14.3](../14-схемотехника-и-доработки.md#s14.3)) в архиве отсутствует, и проверить нечем. В реестре — И15.
  Из таблицы конфигураций ВП1-065 ([§12.6](../12-последовательный-канал.md#s12.6)) вектор `300` получается только в режиме
  `ACL1-0` = 11, где младшие разряды адреса и вектор задаёт внешняя схема по `BS`.
* **КМК и КМК-11.** «КМК» — **контроллер моноканала**, сетевой блок. По
  [РЭ-11М] блок **КМК-11 2.165.007** входит в комплект БК-0011М как сетевой блок машины
  ученика, а машина преподавателя получает **КРМП** — КНГМД и контроллер моноканала
  в одном корпусе ([../20-БК-0011М.md](../20-БК-0011М.md), [§20.10](../20-БК-0011М.md#s20.10)). Сообщество
  сообщает, что в КМК-11 стоит 1801ВП1-035 — предшественник БИС КЛС ([§13.4.5](мышь-УВК-01.md#s13.4.5)).
  Возможно, «блок КМК» с вектором `300` из [РСП-11] — это блок того же семейства,
  а КЛС из [РД-11] — другое исполнение для той же сети. Регистров и вектора КМК-11
  ни один документ не даёт.
* **Протокол сети** (формат кадра, адресация, роль преподавателя) в [РД-11]
  не описан — только аппаратура.
* Начальный пуск ДМС ищет КЛС и при наличии запускает **загрузчик по сети**
  ([../19-БК-0011.md](../19-БК-0011.md), [§19.8](../19-БК-0011.md#s19.8)); монитор умеет загружать файлы
  «из линии» (команда `L`).
