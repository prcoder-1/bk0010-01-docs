# 14.7. Принтеры

> Документ каталога периферии — [../14-периферия.md](../14-периферия.md).
>
> **Источник** — **[Ус]**: Д. Ю. Усенков, «О некоторых периферийных устройствах для БК-0010»
> (начало 1990-х).

Принтер подключается к порту УВВ по протоколу «строб + готовность»: разряды 00–07
порта вывода — код символа, разряд 08 порта вывода — строб, разряд 08 порта ввода —
готовность (контакты — [разъёмы.md](разъёмы.md), §14.1.2; конфликт разряда 08 со
вторым джойстиком — §14.1.3). Подробности протокола и пример драйвера см. в
[../09-монитор.md](../09-монитор.md), §9.9 и §9.10.

Типовые принтеры эпохи — **МС-6312**, **МС-6313**, «Роботрон».

## 14.7.1. МС-6312 [Ус]

Термоструйный: точка печатается «выстреливанием» разогретого состава.

| Параметр | Значение |
| --- | --- |
| Габариты, масса | 53,5 × 170 × 277 мм, не более 3 кг |
| Символов в строке | 80 |
| Скорость печати | 150 знаков/с (шрифт ELITE) |
| Набор знаков | не менее 162 |
| Шаг печати / шаг строк | 2,12 мм / 4,23 мм |
| Матрица символа | 16 × 12 точек |
| Минимальная толщина линии | 0,4 мм |
| Бумага | обычная, формат А4 или рулон той же ширины |

Варианты шрифта: уплотнённый (обычный), расширенный, подчёркнутый, «жирный»
(двойное пропечатывание), линия подчёркивания, верхние индексы, субскрипты.

Управление — **ESCAPE-последовательности**; система команд близка к EPSON-стандарту
(коды инициализации и графического режима — см. пример графического копирования экрана
в [../09-монитор.md](../09-монитор.md), §9.10). Существенный недостаток: пишущий узел
одноразовый и требует замены по мере израсходования.

## 14.7.2. МС-6313 [Ус]

Матричный, девять игл, красящая лента. Габариты 400 × 460 × 100 мм, масса около 8 кг.
Тип шрифта переключается **вручную** движками под крышкой. Канал передачи — **ИРПС-М**
(как в КУВТ-86 для связи с ДВК) либо стык С2; кабели с разъёмами прилагаются.

Твёрдая копия экрана печатается передачей вместо кода символа числа, кодирующего
участок изображения под гребёнкой игл: иглы, соответствующие единичным битам, печатают
точки, нулевым — нет.
