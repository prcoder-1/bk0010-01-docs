# 14.8. Графопостроитель для БК-0010.01

> Документ каталога периферии — [../14-периферия.md](../14-периферия.md).
>
> **Источник** — **[Ус]**: Д. Ю. Усенков, «О некоторых периферийных устройствах для БК-0010»
> (начало 1990-х).

Разработан специально под БК-0010.01, подключается непосредственно к разъёму порта УВВ,
никакой адаптации не требует.

| Параметр | Значение |
| --- | --- |
| Габариты, масса | 80 × 180 × 400 мм, 2,8 кг |
| Бумага | 210 × 297 мм (А4 по ГОСТ 2.301-68) |
| Рабочее поле | 185 × 260 мм |
| Принцип | Роликовый: по одной координате перематывается лист, по второй перемещается зажим пишущего узла |
| Пишущий узел | Фломастер, шариковая ручка, рапидограф или карандаш |
| Шаг | 0,1 мм (точность порядка сотых долей мм) |
| Скорость | до 100 мм/с |

Команда «поднять–опустить перо» позволяет чертить или переносить перо без вычерчивания.
В комплекте — кассета с драйвером в кодах и программой-примером. Драйвер рассчитан
на вызов как **USR-функция вильнюсского Бейсика**
([../10-бейсик.md](../10-бейсик.md), §10.10): данные передаются через специально
отведённые ячейки ОЗУ оператором `POKE`, текст задаётся аргументом `USR`.
Позволяет выводить окружности и эллипсы, линии, точки и текст.
